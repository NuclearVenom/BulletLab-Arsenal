# Security Policy

## Supported Versions

Since this repository primarily consists of static assets, models, and metadata, versioning applies to the metadata schemas and utility scripts.

We support security updates for the `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability within BulletLab Arsenal (e.g., a maliciously crafted URDF or mesh file designed to exploit parsers, or an issue in our validation scripts), please do not report it through public issues.

Instead, please send an email to the BulletLab maintainers. We will respond promptly, assess the vulnerability, and issue a patch or remove the offending asset from the registry.
